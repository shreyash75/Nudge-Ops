# NudgeOps | AI-Powered Kubernetes Incident & Root Cause Analysis

NudgeOps combines Kubernetes diagnostics with LLM-based reasoning to automate incident investigation, identify probable root causes, and generate actionable remediation recommendations.

Capabilities

Kubernetes cluster diagnostics and evidence collection

AI-assisted root cause analysis

Confidence scoring and remediation recommendations

Real-time investigation updates and history

Architecture

Next.js → FastAPI → Kubernetes API → OpenRouter LLM → RCA & Resolutions 

Tech Stack

Frontend: Next.js, TypeScript, Tailwind CSS
Backend: Python, FastAPI
AI: OpenRouter, LLMs
Infrastructure: Kubernetes, Docker
Database: PostgreSQL
